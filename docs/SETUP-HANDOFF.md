# 测试网签名助手交接

入口 `/setup`，生产必须 HTTPS；不依赖 Auth 或已经配置工厂。当前仅本地修订，尚未发布。PR #1 的 Vercel 预览失败原因仍待真实日志，不因此合并。

仅钱包 A 发送四笔：部署冻结 MockUSDC；部署绑定其地址的 FanPoolFactory；分别向 A、B 各 mint 1000 MOCK。链 10143，每笔 value=0。B 是收币地址，无需为收币签名；业务供应商/履约地址另行确认。

每一步先点击“准备未签请求与费用”，核对目标、data hash、gas 与费用上限，再单独点击“打开钱包确认本笔”。钱包可能自行调整报价，以最终钱包显示为准。不会自动发送下一笔，不查询 MON 余额或 faucet。用户始终自行确认钱包请求。

拿到 hash 后点击“仅核验原交易”；等待 finalized、成功回执、固定发送人/输入/nonce/区块与 runtime 校验通过，才可准备下一步。刷新重新核验公开 hash，浏览器“完成”标记不授予权限。Factory runtime 按固定 token immutable 插槽比对；mint 检查固定收款人与数量事件及 MOCK 余额快照。

拒签可重新准备当前步骤。钱包请求结果未知时，原发送意图会阻止重发；从钱包活动复制原交易 hash，在对应恢复框核验。持久化失败发生在发送前则不弹交易请求；返回 hash 后写失败则保留内存 hash 并提示复制，刷新保留旧意图但需手动恢复。不要清理浏览器数据或另换设备来绕过未知交易锁。已失败上链交易保留记录，不自动再次部署，需负责人核查。

要求支持 Web Locks 的浏览器；缺失时停止发送。所有本地记录均为公开交易信息，不能替代链上验证。清空所有站点数据会失去本地防重复意图，故上线操作应使用同一浏览器并保留 hash。

真实桌面/手机钱包及四笔链上结果仍待用户参与。后续独立记录 status/from/input/地址/finalized/code 与收款余额变化；本地 provider 测试不等于真实钱包或测试网成功。
